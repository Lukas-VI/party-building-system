# 党员发展管理系统改进清单

## 一、申请人端（手机端）

### 1.1 工作台数据看板
- [x] **隐藏敏感数据**（申请人不可查看"申请人数"和"待注册审核人数"）`[清单]`
- [x] **保留可见项**（仅显示"待流程审核数"和"审批数量超出预警数"）`[清单]`
- [x] **PC端同步**（PC端对申请人无实际意义，数据与移动端一致）`[清单]`
- [ ] **上传文件无法删除/撤销**（基础 CRUD 缺失，上传后无任何方式撤回）`[Issue#1-P1]`

### 1.2 流程记录展示优化
- [ ] **倒序排列**：流程记录按办理时间倒序展示，最新办理步骤置顶 `[清单]`
- [ ] **高亮当前步骤**：当前待办理步骤（如第13步）醒目标识，无需滚动查找 `[清单]`
- [ ] **办理状态区分**：已办理步骤置后折叠，待办理步骤前置展开 `[清单]`
- [ ] **完成所有节点后**：不显示第一个节点，显示"流程已全部完成"，隐藏"当前节点" `[重叠]`
- [ ] **审批结果用词归口**：通知类→"同意"/"不同意"→确认；提交类→"通过"/"不通过"→确认 `[Issue#1-P0]`

### 1.3 提交与上传
- [ ] **提交时间精度**：申请书等文件中"提交时间"精确到日即可（当前含时分秒）`[Issue#1-P0]`
- [ ] **PDF预览修复**：上传后预览不空白，审核界面预览不触发下载 `[Issue#1-P0]`
- [ ] **删除/撤回上传文件**：上传后可删除，撤销操作 `[Issue#1-P1]`

### 1.4 消息与改期
- [ ] **底部bar红点提醒**：有未读消息时底部导航图标上显示红点 `[Issue#1-P1]`
- [ ] **改期功能折叠**：申请改期入口默认折叠，需要时展开 `[重叠]`
- [ ] **改期时间选择器**：提供时间选择菜单，而非纯文本输入 `[Issue#1-P3]`

### 1.5 UX 体验
- [ ] **全局返回按钮**：每个页面顶部左上角有 `< 返回` `[Issue#1-P1]`
- [ ] **过渡动画**：页面切换、资源加载、列表、折叠展开都加上过渡动画 `[Issue#1-P3]`
- [ ] **输入法适配**：底部 bar 不随输入法上移 `[Issue#1-P2]`
- [ ] **节点详情页整洁**：删除冗余的 blessingText 祝福提示类文字 `[Issue#1-P2]`

## 二、党支部书记端

### 2.1 工作台首页
- [ ] **修正术语**：
  - "待注册审核" → "注册待审核"
  - 明确区分"注册待审核"与"待流程审核"的业务含义 `[清单]`
- [ ] **超期预警**："超期事项"显示未审批且已超期的申请数量 `[清单]`
- [ ] **阶段分布可下钻**：
  - 发展对象、积极分子等人数支持点击展开
  - 展开显示：姓名、支部、年级、学号等简要信息
  - 嵌入式表格（在当前页展开），不跳转新页面 `[清单]`

### 2.2 单位统计模块
- [ ] **调整列顺序**：单位名称前置，阶段分布后置 `[清单]`
- [ ] **精简核心指标（3列）**：申请人数、发展中人数、正式党员人数 `[清单]`
- [ ] **移除冗余**：删除"入门阶段"等模糊表述 `[清单]`
- [ ] **扩展指标（后续迭代）**：发展比例 = 发展中人数 / 申请人数 `[清单]`

### 2.3 数据导出
- [ ] **导出内容**：所有在发展中人员的基本信息及当前流程节点 `[清单]`
- [ ] **导出格式**：支持统一表格下载 `[清单]`

### 2.4 超期与统计精度
> 注意：以下条目直接影响 2.1 超期预警和 2.2 指标的数字准确性，建议优先实现。
- [ ] **通知类节点流程**：审核人填写地点/时间 → 系统发送消息 → 申请人才能看到"进行中"；申请人在收到消息前显示"未开放" `[Issue#1-P0]`
- [ ] **提交类节点待办规则**：申请人提交后，节点才进入审核人待办；申请人未提交时审核人看不到 `[Issue#1-P0]`
- [ ] **快捷入口数字实时算**：待审核节点数量通过后端实时计算，不依赖缓存或前端 `[Issue#1-P1]`

## 三、审核审批模块

### 3.1 列表页优化
- [x] **调整列顺序**：
  1. 单位（学院）
  2. 支部
  3. 姓名
  4. 学号
  5. 步骤序号（如第13步）
  6. 当前状态（原"步骤"→"当前状态"，如"政治审查"）
  7. 截止时间
  8. 操作：查看流程 / 通过 / 退回 `[清单]`

### 3.2 状态机与操作
- [x] **角色撤回**：桌面端编辑人员信息后，赋予的多重角色无法撤回 → 需支持角色撤销 `[Issue#1-P1]`
- [ ] **删除"流程资格确认"**：当前流程中有冗余的资格确认节点，需删除 `[Issue#1-P0]`
- [ ] **通知实时刷新**：审核人操作后，申请人端不轮询也能在合理时间内看到状态变化（WebSocket 或短轮询）`[Issue#1-P1]`

### 3.3 审核界面详情
- [x] **申请人信息字号放大**：审核界面详情中申请人姓名、学号等信息太小，看不清 `[重叠]`
- [ ] **审核中预览修复**：审核时预览 PDF 不再空白或触发下载 `[Issue#1-P0]`
- [x] **任务卡片申请人名字放大**：审核人的待办卡片中申请人姓名应更醒目 `[Issue#1-P1]`

### 3.4 桌面端布局
- [x] **右侧独立滚动容器**：保持左侧菜单固定，右侧内容独立滚动 `[Issue#1-P3]`
